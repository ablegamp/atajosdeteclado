El poder de una lista de tareas bien gestionada

Los profesionales más productivos procesan 50+ tareas al día. El 90% del tiempo perdido viene de buscar qué hacer después y cambiar entre aplicaciones. Workflows Profesionales con Todoist

☀️ Workflow: Revisión Matutina (5 minutos)

  1. G+H → Ver tareas de Hoy
  2. Revisar y reordenar: Ctrl+↑/↓
  3. Marcar prioridades: 1, 2, 3
  4. G+I → Procesar bandeja de entrada
  5. Cada tarea: asignar proyecto V o fecha D
  6. G+U → Revisar próximos días

⏱️ Resultado: Día planificado, bandeja vacía, control total

⚡ Workflow: Captura Rápida de Ideas

  1. Q → Abre añadir tarea rápida
  2. Escribe la idea completa con contexto
  3. Añade #Ideas o #Bandeja
  4. Enter → Guardado, sigue trabajando
  5. Procesa después en la revisión matutina

Clave: Captura rápido, procesa después. No interrumpas tu flujo actual.

📋 Workflow: Gestión de Proyecto

Estructura recomendada: 
📁 Proyecto Lanzamiento Web
  ├── 🔴 [p1] Definir requisitos
  │   ├── Reunión con cliente mañana 10am
  │   └── Documentar especificaciones
  ├── 🟠 [p2] Diseño
  │   ├── Wireframes #diseño @pendiente
  │   └── Mockups
  └── 🔵 [p3] Desarrollo
      ├── Frontend cada día laborable
      └── Backend

Atajos clave:

  • A → Añadir tareas al proyecto
  • Tab → Crear subtareas
  • 1-4 → Asignar prioridades
  • V+B → Vista Kanban del proyecto

🎯 Workflow: Sistema GTD (Getting Things Done)

Proyectos GTD en Todoist:
  • 📥 Bandeja de entrada - Todo entra aquí (Q)
  • 📋 Próximas acciones - Filtro: p1 y hoy
  • ⏳ En espera - Etiqueta @espera
  • 📅 Algún día - Sin fecha, proyecto Algún día
  • 📚 Referencia - Notas y recursos
Procesamiento 2 minutos: Si toma menos de 2 min, hazlo ya con C. Si no, programa (D) o delega (@espera).

🌙 Workflow: Revisión Semanal

  1. G+I → Vaciar bandeja de entrada completamente
  2. G+P → Revisar cada proyecto activo
  3. / → Buscar @espera - hacer seguimiento
  4. G+U → Revisar próximas 2 semanas
  5. Reprogramar lo que no vas a hacer: N (próxima semana)
  6. Celebrar completadas: revisar Karma en perfil 🎉
⏱️ Duración: 30-60 minutos cada domingo o viernes

🎯 Desafío: Domina Todoist en 7 días

Plan de aprendizaje progresivo:

Día 1-2: Solo usa Q para añadir tareas y C para completar
Día 3: Aprende navegación G+H, G+U, G+I
Día 4: Domina fechas: T, M, N, D
Día 5: Organiza con Tab (subtareas) y prioridades 1-4
Día 6: Proyectos (#) y etiquetas (@)
Día 7: Crea tu sistema GTD personalizado

Meta: Añadir tarea en <3 segundos, bandeja siempre vacía, nada se olvida

Preguntas frecuentes sobre atajos de Todoist

¿Cuál es el atajo más útil en Todoist?
La tecla Q para añadir tarea rápida es el atajo más útil. Desde cualquier vista, incluso con Todoist minimizado, presiona Q y aparece el cuadro de añadir tarea con soporte completo para lenguaje natural. Puedes escribir "Llamar al cliente mañana a las 10 p1 #Trabajo @urgente" y Todoist interpreta automáticamente la fecha, hora, prioridad, proyecto y etiqueta. Todo en un solo paso, sin usar el ratón.
¿Cómo navegar rápidamente entre vistas en Todoist?
Usa la tecla G (de "Go") seguida de otra letra: G+H para Hoy, G+U para Próximo (Upcoming), G+I para Bandeja de entrada, G+P para Proyectos, G+L para Etiquetas, G+F para Filtros. Para cambiar el tipo de vista actual: V+D (día), V+W (semana), V+L (lista), V+B (tablero Kanban).
¿Cómo usar el lenguaje natural en Todoist?
Todoist interpreta fechas en español automáticamente: "hoy", "mañana", "próximo lunes", "en 3 días", "cada viernes", "15 de enero a las 14:00". También reconoce prioridades (p1, p2, p3, p4), proyectos (#NombreProyecto), etiquetas (@etiqueta), asignaciones (+nombre de colaborador) y descripciones (// texto). Todo esto funciona directamente mientras escribes la tarea, sin necesidad de abrir menús adicionales.
¿Qué atajos usar para organizar tareas en Todoist?
Para mover tareas arriba/abajo: Ctrl+↑/↓. Para crear subtareas (sangrar): Tab. Para quitar sangría: Shift+Tab. Para seleccionar múltiples tareas: X en cada tarea, o Ctrl+A para seleccionar todas. Para completar: C. Para editar: E. Para eliminar: Backspace o Delete en tarea seleccionada. Para mover a otro proyecto: V.
¿Cómo cambiar fechas rápidamente en Todoist?
Selecciona una tarea y usa estos atajos de una tecla: T para hoy, M para mañana, N para próxima semana, O para quitar fecha, D para abrir el selector de fecha completo. También puedes usar prioridades rápidas: 1, 2, 3, 4 para asignar prioridad directamente.
¿Dónde puedo ver todos los atajos de Todoist?
Presiona ? (signo de interrogación) en cualquier momento dentro de Todoist para abrir la lista completa de atajos de teclado. Esta referencia rápida incluye todos los atajos disponibles, organizados por categoría. Es muy útil mientras aprendes, ya que puedes consultarla sin salir de la aplicación.
