Atajos de teclado 2025: lista definitiva

La lista definitiva para acelerar tu día a día. Atajos universales y esenciales en Windows y Mac: texto, navegación, ventanas, búsqueda, capturas y más.

Actualizado el 05/12/2025

Atajos de teclado: edición de texto y portapapeles

Copiar, pegar y edición rápida (Windows / Mac)

Acción Combinación Descripción
Copiar Ctrl/⌘ + C Copia selección al portapapeles
Cortar Ctrl/⌘ + X Mueve selección al portapapeles
Pegar Ctrl/⌘ + V Pega desde el portapapeles
Deshacer / Rehacer Ctrl/⌘ + Z / Ctrl/⌘ + Y/⇧+Z Revierte o repite cambios
Seleccionar todo Ctrl/⌘ + A Selecciona todo el contenido
Buscar / Reemplazar Ctrl/⌘ + F / Ctrl/⌘ + H Encuentra y reemplaza texto

Atajos de teclado para navegación rápida y productividad

Cambia entre apps, busca y ejecuta acciones al instante

Acción Combinación Descripción
Cambiar de aplicación Alt + Tab (Win) / ⌘ + Tab (Mac) Alterna entre apps abiertas
Buscar en el sistema Win (escribir) / ⌘ + Espacio Abrir búsqueda de Windows o Spotlight
Ejecutar comando Win + R (Win) / ⌘ + Shift + . (varía) Abre cuadro de ejecutar / lanzadores
Bloquear pantalla Win + L / Ctrl + ⌘ + Q Bloquea la sesión
Emoji y símbolos Win + . / Ctrl + ⌘ + Espacio Abre panel de emoji y símbolos

Atajos de teclado para gestión de ventanas y escritorios

Organiza tu espacio de trabajo en segundos

Acción Combinación Descripción
Mitad izquierda / derecha Win + ←/→ (Win) / ⌘ + ⌥ + ←/→ (apps) Ajusta ventanas a mitad de pantalla
Maximizar / Minimizar Win + ↑/↓ / ⌘ + M Gestiona tamaño de ventanas
Vista de tareas / Mission Control Win + Tab / Ctrl + ↑ Ver apps y escritorios virtuales
Nuevo escritorio Win + Ctrl + D / Ctrl + ↑ luego + Crea un escritorio virtual
Cambiar escritorio Win + Ctrl + ←/→ / Ctrl + ←/→ Navega entre escritorios

Pestañas, zoom y búsquedas rápidas

Acción Combinación Descripción

Reabrir pestaña cerrada Ctrl/⌘ + Shift + T Recupera la última pestaña cerrada

Preguntas frecuentes sobre atajos de teclado

¿Cuáles son los atajos de teclado más usados en 2025?

Copiar, pegar, deshacer, buscar, cambiar de aplicación y gestionar pestañas siguen siendo los atajos de teclado más usados a diario en Windows y Mac.

¿Qué atajos de teclado aceleran más mi trabajo?

Aprende combinaciones para selección de texto, navegación por pestañas, gestión de ventanas y búsqueda del sistema. Son los que más impacto tienen en productividad.

¿Los atajos de teclado son iguales en Windows y Mac?

La mayoría de acciones son equivalentes: en Mac usa ⌘ donde en Windows se usa Ctrl, con variaciones puntuales según la app.

¿Cómo memorizar atajos de teclado rápidamente?

Empieza por 5 atajos clave, repítelos durante una semana y añade 2-3 nuevos cada pocos días. Coloca una chuleta visible junto al monitor.
